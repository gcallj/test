# Invest in a broad Swedish index fund; stop developing active strategies

Seven active strategies (v1–v7) were judged out of sample with frozen specs
and single runs, and none beat `^OMXSBGI` after ISK costs. Criterion 1 of the
plan says that when the system cannot beat the index benchmark, the owner
holds the index. The 30,000 SEK go into a low-cost, accumulating, broad
Swedish index fund in an ISK; no signal, daily run or ramp-up is needed.

## Consequences

The code and reports stay as the record of what was tried
(`docs/sweden/conclusao.md`). A new strategy may only be judged on data no
earlier version used — paper trading forward, or a new universe with
delisted prices — with its spec frozen first.
